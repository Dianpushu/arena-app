## v0.1.0-beta.4 — 修復複製按鈕沒有作用

這是 Arena 非官方 Windows 桌面客戶端的 Beta 測試版本，可能仍有錯誤，不建議用於重要工作。此版本標示為 Pre-release，不作為正式版發布。

### 本版修正

- **修正網站的「複製對話」「複製程式碼」等複製按鈕按下去沒有作用的問題。** 按鈕不會變成打勾、剪貼簿也是空的，是 beta.3 收緊通知權限時的副作用：桌面版對通知以外的所有權限一律拒絕，連 Chromium 用來實作 `navigator.clipboard.writeText()` 的剪貼簿權限也被擋掉，網站收到 `NotAllowedError` 後多半不會顯示錯誤，看起來就像按鈕壞掉。
- 修正從分頁列、工具列或網址列操作後，鍵盤焦點留在桌面版自己的介面上，導致網頁複製以「Document is not focused」失敗。切換、新增、關閉分頁與網址列導覽後會把焦點交還網頁。
- 修正右鍵選單的剪下／複製／貼上／全選在多分頁情境下可能作用到錯誤頁面的問題，現在明確綁定被右鍵的那個分頁。
- 右鍵連結新增「複製連結網址」。

### 剪貼簿權限說明

放行範圍刻意保持最小，只開放複製按鈕實際需要的部分：

- **寫入剪貼簿**（複製按鈕）：允許一般網頁使用。必須由你的點擊觸發，且只能寫入純文字等標準格式；網頁無法藉此讀取你剪貼簿裡原本的內容。
- **讀取剪貼簿**：僅允許 `arena.ai` 與其子網域，其他網站一律拒絕，避免任意網頁靜默讀走剪貼簿。
- 已淘汰的同步剪貼簿 API、本機檔案與自訂協定頁面一律拒絕。
- 相機、麥克風、定位、螢幕擷取等其他權限維持全部拒絕，本版沒有放寬。

### 下載與安裝

- **Arena-Setup-版本號.exe**：安裝精靈版，支援自動更新。
- **Arena-版本號-portable.exe**：免安裝版，下載後直接執行；不支援自動更新。
- `beta.yml` 與 `.blockmap` 為更新所需檔案，一般使用者不需手動下載。

適用於 Windows 10（1809 以上）／Windows 11，64 位元。

### 測試重點

- 請先完全結束舊版（包含系統匣圖示），再啟動新版；否則單一實例機制可能只會叫回舊版視窗。
- 在對話中按「複製」，確認按鈕出現打勾，並在別處貼上確認內容正確。
- 在程式碼區塊按「複製程式碼」，確認貼上的是完整程式碼。
- 開多個分頁，切換到別的分頁再切回來，立刻按複製，確認仍然有效。
- 在輸入框與選取文字上按右鍵，確認剪下／複製／貼上／全選作用在正確的頁面；在連結上按右鍵確認「複製連結網址」。
- 設定內版本應顯示 `0.1.0-beta.4`。

### 已完成驗證與已知限制

- 已通過 lint、格式檢查、TypeScript 型別檢查、前端與 Electron 編譯，以及 Windows NSIS／portable 打包。
- 新增剪貼簿權限的單元測試（權限名稱、來源網域、協定、來源欄位退回），釘住「複製放行、讀取僅限 Arena、其餘全拒」。
- 新增 Windows 真實 Electron 環境的自動化回歸測試：由網頁呼叫 `navigator.clipboard.writeText()` 並驗證系統剪貼簿確實收到內容，同時確認非 Arena 來源的讀取仍被拒絕。
- 尚未完成人工 Windows 實機驗收與自動更新端到端測試，歡迎回報測試結果。
- 安裝檔未配置程式碼簽署，Windows SmartScreen 可能顯示警告。請確認下載來源為本儲存庫，並自行評估後再執行。
- 本專案與 arena.ai 官方無關。
