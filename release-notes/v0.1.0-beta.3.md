## v0.1.0-beta.3 — 穩定性與安全性改進

這是 Arena 非官方 Windows 桌面客戶端的 Beta 測試版本，可能仍有錯誤，不建議用於重要工作。此版本標示為 Pre-release，不作為正式版發布。

### 本版修正

- 修正 Release workflow 被 release notes 阻擋的問題，建立版本化 release notes 目錄。
- 修正通知權限過度自動授權：僅允許 `arena.ai` 與 `*.arena.ai` 網域的通知，並加入 permission check handler。
- 修正全域快捷鍵註冊失敗時舊快捷鍵被清除的問題，加入自動回滾機制。
- 為 SettingsStore 加入自動重試機制（100ms / 300ms / 700ms / 1500ms），避免 Windows 暫時性 I/O 鎖定導致設定遺失。
- 加入分頁數量上限（32 個），避免無限建立分頁導致記憶體持續增加；啟動還原時僅還原前 32 個分頁。
- 修正視窗座標可能讓 App 開在螢幕外的問題，啟動時檢查是否落在可見螢幕範圍內。
- 修正 Prettier 格式檢查失敗，新增 `format:check` 腳本並加入 CI。
- 其他細節優化與測試補強。

### 下載與安裝

- **Arena-Setup-版本號.exe**：安裝精靈版，支援自動更新。
- **Arena-版本號-portable.exe**：免安裝版，下載後直接執行；不支援自動更新。
- `beta.yml` 與 `.blockmap` 為更新所需檔案，一般使用者不需手動下載。

適用於 Windows 10（1809 以上）／Windows 11，64 位元。

### 已知限制

- 安裝檔未配置程式碼簽署，Windows SmartScreen 可能顯示警告。
- 本專案與 arena.ai 官方無關。
